# Fourier-Neural-Operator
A few experiences on Fourier Neural Operators. 
- **time_dependent_bc**: FNO architecture on a 2D reaction-diffusion PDE with time-dependent Neumann boundary conditions. This has been done after finding mixed opinions on whether FNO can be used with non homogeneous Neumann boundary conditions.
- **blurredprediction**: Exploring why inferences on odd grid size fail with a FNO trained on a standard 2D diffusion-reaction PDE.
